# Доступ к GitHub Pages

Форма пароля в статической сборке предназначена только для защиты от случайного просмотра. GitHub Pages не выполняет серверный код, поэтому `news.json`, изображения и хэш пароля доступны посетителю через инструменты разработчика.

Не публикуйте в этой сборке секретные или чувствительные материалы. Для настоящего контроля доступа нужен серверный хостинг с аутентификацией либо приватный GitHub Pages в организации GitHub Enterprise Cloud.
