# Агентская лента

Локальное приложение для чтения Markdown-новостей из папки. Работает на Python без сторонних пакетов и слушает только `127.0.0.1`.

## Запуск

Откройте «Агентская лента» в меню приложений XFCE или выполните:

```bash
/home/admin/agent-news/run.sh
```

Интерфейс: <http://127.0.0.1:8765>

Папка новостей по умолчанию: `/home/admin/agent-news/news`. При необходимости её можно поменять в `config.json`.

## Формат новостей

Обычный Markdown уже поддерживается. Для красивой карточки можно добавить YAML-подобный блок:

```markdown
---
title: Заголовок
date: 2026-11-20T18:30:00+03:00
category: Технологии
source: Агент
tags: [ИИ, релиз]
priority: high
url: https://example.com
summary: Краткий анонс.
image: ./images/cover.jpg
---

Основной текст новости.

![Фото внутри статьи](./images/detail.jpg)
```

Поддерживаемые поля: `title`, `date`, `category`, `source`, `tags`, `priority`, `url`, `image`, `summary`. Локальные изображения PNG, JPEG, WebP, GIF и AVIF можно хранить рядом с новостью; пути считаются относительно `.md`-файла. Внешние `https://`-изображения тоже поддерживаются.

## GitHub Pages

Статический снимок ленты собирается в `dist/`:

```bash
python3 build_pages.py --password-stdin
```

Введите пароль через стандартный ввод. В сборке сохраняется только salted SHA-256-хэш. Workflow `.github/workflows/pages.yml` публикует готовую папку `dist` при push в `main`.

GitHub Pages не поддерживает Python и настоящую серверную авторизацию. Форма пароля скрывает интерфейс, но не делает опубликованные Markdown-данные и изображения секретными; подробности находятся в `SECURITY.md`.
