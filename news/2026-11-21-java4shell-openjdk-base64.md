17 ноября 2026 года Oracle в ноябрьском обновлении безопасности выпустила исправление для CVE-2026-114938, уязвимости в декодере Base64 виртуальной машины Java. Исследователи Calif.io, которым Oracle приписывает обнаружение, называют её Java4Shell.

## Суть ошибки

- Проблема находится в AVX-512 подпрограмме HotSpot. JIT-компилятор использует её для быстрого декодирования Base64 в «горячем» коде.
- При обработке неполного хвоста входных данных вычисляется отрицательная длина, и запись выходит за границы массива на 62–63 байта.
- Oracle оценивает уязвимость в 8,1 (High) по CVSS 3.1 и описывает возможный результат как захват затронутого продукта. Ранние оценки CVSS 4.0 в 9,2 появились в публикациях сторонних исследователей; их источник не назван.
- Аутентификация не требуется, но входные данные должны попасть в декодер Base64, например через заголовок авторизации, токен или cookie.
- На момент публикаций, которые я смог проверить, подтверждённой эксплуатации в природе нет, а CISA KEV уязвимость не включала. Один из связанных материалов SecurityWeek упоминает «попытки эксплуатации», но первоисточника я не нашёл, поэтому не утверждаю это как факт.

## Какие версии затронуты

- **Затронуты:** Java 17.0.6–17.0.21, Java 21 до 21.0.13.1, Java 25 до 25.0.5.1 и Java 27 до 27.0.1.1 на x86-64 с AVX-512.
- **По независимым анализам, не затронуты:** Java 11 и серверы на ARM, например Graviton, Ampere и Apple Silicon.
- Сборки Temurin, Corretto, Red Hat и других поставщиков тоже нужно обновлять у их вендоров.

## Что делать

1. Обновить OpenJDK или Oracle JDK до исправленной сборки. По данным Exein и Sysdig, это 17.0.21.1, 21.0.13.1, 25.0.5.1 или 27.0.1.1, либо сборка вашего вендора.
2. Если обновиться сразу нельзя, запускать JVM с флагом `-XX:-UseBASE64Intrinsics`. По данным Horizon3 и Sysdig, он устраняет уязвимый путь, но Oracle не публикует его как поддерживаемый обходной путь, а декодирование Base64 станет медленнее. Флаг действует только после перезапуска JVM.
3. Проверить версии рантайма в контейнерах и образах, которые поставляются вместе с приложениями.
